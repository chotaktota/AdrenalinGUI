# Изображения

`wordmark.png` — объёмная надпись AdrenalinGUI из красного металла на чёрном фоне, обложка английского и русского README. Создана встроенным инструментом imagegen 21 ноября 2026 года. Полный запрос сохранён в [wordmark-prompt.txt](wordmark-prompt.txt). Название и красно-чёрное направление выбраны пользователем.

`help-layout.svg` — схема главной страницы HelpGUI, построенная по шаблону из примера. Это не скриншот Minecraft. Схема находится в разделе примеров, отдельно от логотипа.

`benchmark-open.png` — график сохранённых измерений; столбцы показывают медиану, отметки — p95. Скрипт построения находится в benchmarks/plot.py.

Оформление переработано с использованием unslop, Damir Sokolovsky ([@heydamir](https://x.com/heydamir)), CC BY 4.0: https://github.com/heydamir/unslop.
