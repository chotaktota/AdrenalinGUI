# Текст и плейсхолдеры

Заголовки, названия предметов, лор и причины отказа принимают MiniMessage и legacy. PlaceholderAPI подставляет значения для конкретного игрока.

## Форматирование

~~~kotlin
title("<red>Профиль <white>%player_name%")

iconAt(pos('P')) {
    type(Material.PAPER)
    name("&fИгрок: <red>%player_name%")
    loreLine("<gray>Баланс: <gold>%vault_eco_balance%")
    loreLine("&#FF5555Поддерживаются HEX-цвета")
    loreLine("<gradient:#ff5555:#ffaa55>Градиент текста</gradient>")
}
~~~

Поддерживаются &a, §a, &l, &r, &#A1B2C3 и шестизначная форма &x&A&1&B&2&C&3. Legacy-цвет сбрасывает предыдущие декорации. MiniMessage-теги сохраняют собственные аргументы.

## PlaceholderAPI

1. Установите PlaceholderAPI.
2. Установите и загрузите расширения для своих токенов, например Player и Vault.
3. Используйте токены %...% в title, name и loreLine.
4. После изменения значения вызовите refresh нужного слота или откройте меню снова.

Плейсхолдеры вычисляются при открытии и refresh. Без PlaceholderAPI текст с токенами остаётся исходным. Автоматический опрос значений не запускается.

## Заголовок окна

Заголовок вычисляется при открытии окна. refresh обновляет предметы. Для нового заголовка после изменения значений откройте меню повторно.

## Сообщения игроку

Форматирование библиотеки относится к её текстовым методам. Вызов player.sendMessage(String) использует правила самого Bukkit и Adventure. Для обычного сообщения можно передать простой текст.
