# Анимации по тикам

Шаги устанавливают, скрывают, показывают и изменяют предметы. По умолчанию последовательность проигрывается один раз.

## Последовательность

~~~kotlin
animation {
    at(0) { hide(pos('X')) }
    at(10) { show(pos('X')) }
    at(20) {
        change(pos('X')) { player ->
            name("<red>Привет, " + player.name)
            lore("<gray>Предмет изменён на двадцатом тике")
            glow()
        }
    }
    at(30) {
        set(pos('X')) {
            type(Material.EMERALD)
            name("<green>Готово")
            onClick { close() }
        }
    }
    loop(60)
}
~~~

Блок объявляется внутри Pattern рядом с iconAt.

## Операции

| Операция | Поведение |
| --- | --- |
| set(slots) | Заменить предмет вместе с обработчиком клика |
| hide(slots) | Скрыть предмет и отключить его обработчик |
| show(slots) | Показать сохранённый предмет |
| change(slots) | Изменить динамические свойства предмета |
| loop(period) | Повторять последовательность |

Каждая операция принимает отдельный слот или набор слотов.

## Время и остановка

at(0), at(10) и at(20) задают моменты относительно открытия страницы. При 20 TPS десять тиков занимают примерно полсекунды. Период loop должен быть больше последнего тика.

Анимация принадлежит сессии игрока. Закрытие, переход страницы, выход игрока и отключение плагина останавливают её. Устаревший клик по заменённой кнопке отбрасывается.

Поля для предметов защищены от пересечения с шагами анимации. Обновление изменяет затронутые слоты.
