# Ввод через чат

inputChat закрывает меню и перехватывает следующий ответ игрока. Результат преобразуется в указанный тип.

## Типизированный ввод

~~~kotlin
onClick {
    inputChat<Int>("Введите количество", timeoutTicks = 600) {
        validate { it in 1..64 }

        onSuccess { amount ->
            sendMessage("Получено число: " + amount)
        }

        onFailure { reason ->
            sendMessage("Ввод завершён: " + reason)
        }
    }
}
~~~

onSuccess и onFailure выполняются на основном потоке с Player в качестве receiver. validate проверяет уже преобразованное значение.

## Поддерживаемые типы

| Тип | Поведение |
| --- | --- |
| String | Непустая строка после trim |
| Int, Long | Целое число соответствующего диапазона |
| Double, Float | Конечное число |
| Boolean | true, false, да, нет |

Также доступна перегрузка с Class, например inputChat("Введите число", Int::class.java).

## Завершение ввода

| Причина | Значение |
| --- | --- |
| INVALID_INPUT | Не удалось преобразовать ответ или validate вернул false |
| CANCELLED | Игрок написал отмена или cancel |
| TIMEOUT | Истекло время ожидания |

Причины объявлены в OtherAction.InputFailure. Время задаётся в тиках, по умолчанию 1200.

Успех, ошибка, отмена и таймаут завершают ожидание. Для новой попытки снова вызовите inputChat из открытого меню. Перехваченный ответ не попадает в общий чат, последующие сообщения работают как обычный чат.

Выход игрока, новое открытое окно и отключение плагина очищают ожидание.
