# Меню для Minecraft-плагинов на Kotlin

AdrenalinGUI — отдельный серверный плагин и библиотека для ваших меню. Опишите расположение предметов, оформление и действия в Kotlin, затем зарегистрируйте меню в своём плагине.

## Что умеет библиотека

- **Расположение по символам.** Девять символов задают строку инвентаря. Один символ может заполнить несколько слотов.
- **Страницы в одном классе.** Главная страница, категории и переходы объявляются в MultiGUISurface.
- **Предметы с данными игрока.** MiniMessage, legacy и PlaceholderAPI работают в заголовках, названиях и лоре.
- **Действия прямо в кнопке.** Инвентарь, экономика, права, ввод через чат и звуки доступны внутри onClick.
- **Поля для предметов.** Игрок кладёт свой предмет, фильтр проверяет его, обработчики пересчитывают состояние меню.
- **Условия доступности.** Кнопка показывает причину отказа и повторно проверяет условие перед выполнением действия.
- **Анимация по тикам.** Установите, измените, скройте или покажите предмет на нужном шаге.

## Как устроено меню

Поверхность хранит описание и кэш прототипов. При открытии каждый игрок получает собственную сессию, инвентарь и копии предметов. Значения для игрока вычисляются при открытии и явном refresh.

Обычный обработчик кнопки выполняется на следующем тике основного потока. Из него можно безопасно открывать другую страницу или закрывать окно.

## С чего начать

1. Установите серверный JAR AdrenalinGUI.
2. Добавьте compileOnly-зависимость в свой плагин.
3. Создайте класс SingleGUISurface или MultiGUISurface.
4. Зарегистрируйте его экземпляр и откройте меню игроку.
