# Регистрация и жизненный цикл

Реестр хранит экземпляры меню и их плагины-владельцы. Сессия относится к одному открытому окну игрока.

## Реестр меню

~~~kotlin
engine.menus.register("help", HelpGUI(this))
engine.open("help", player)

val menu = engine.menus.find("help")
val registered = engine.menus.entries()
engine.menus.unregister("help")
~~~

Идентификаторы должны быть непустыми и уникальными. entries возвращает снимок регистраций. Каждый экземпляр поверхности знает свой plugin.

## События поверхности

~~~kotlin
override fun onOpen(player: Player) {
    player.sendMessage("Меню открыто")
}

override fun onClose(player: Player) {
    player.sendMessage("Меню закрыто")
}
~~~

В MultiGUISurface эти методы также получают page: String. При переходе страницы старая сессия закрывается, новая открывается.

Создавайте экземпляр меню один раз, например в onEnable своего плагина. Для каждого игрока AdrenalinGUI самостоятельно создаёт отдельную сессию.

## Команда администратора

~~~text
/guis info
/guis info help
/guis info --page 2
~~~

Нужно право adrenalingui.admin. Команда показывает регистрации, плагин-владелец, тип поверхности, класс, размер и начальную страницу. Она не строит и не открывает окна.

## Завершение работы

При отключении плагина его сессии закрываются, поля возвращают предметы, ожидание чата очищается, а регистрации удаляются. Анимации и отложенные действия не продолжаются после остановки движка.
