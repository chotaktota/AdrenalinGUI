# Шаблоны и слоты

Шаблон задаёт расположение предметов. Он содержит ровно столько строк, сколько указано в размере поверхности или страницы.

## Девять символов в строке

~~~kotlin
with(newPattern("""
    AAAAAAAAA
    A...X...A
    AAAAAAAAA
""".trimIndent())) {
    title("<red>Меню")

    iconAt(pos('A')) {
        type(Material.RED_STAINED_GLASS_PANE)
        name(" ")
        allFlags()
    }

    iconAt(pos('X')) {
        type(Material.ENDER_EYE)
        name("<white>Открыть")
    }
}
~~~

Точка обозначает пустое место. pos возвращает все позиции символа. Регистр и сами символы имеют значение.

## Индексы слотов

Нумерация идёт с нуля, слева направо и сверху вниз. В меню на три строки доступны слоты 0–26.

~~~kotlin
iconAt(13) {
    type(Material.BOOK)
    name("<white>Центр")
}

iconAt(listOf(0, 8, 18, 26)) {
    type(Material.RED_STAINED_GLASS_PANE)
    name(" ")
}
~~~

Для одной позиции символа используйте pos('X').first(). Для всей группы передайте pos('X') в iconAt.

## Проверки шаблона

- Поверхность и страница содержат от одной до шести строк.
- Каждая строка содержит ровно девять символов.
- Символ, переданный в pos, должен присутствовать в шаблоне.
- Поля для предметов защищены от пересечения с иконками и анимацией.
- Источник и целевой слот связанного поля должны различаться.
