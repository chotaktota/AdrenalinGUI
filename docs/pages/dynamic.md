# Динамические иконки и кэш

Постоянное оформление собирается один раз. Значения, зависящие от игрока и текущих параметров, вычисляются в dynamic.

## dynamic

~~~kotlin
iconAt(pos('X')) {
    type(Material.EXPERIENCE_BOTTLE)
    dynamic { player ->
        name("<white>Уровень: <red>" + player.level)
        lore("<gray>Игрок: " + player.name)
        glow(player.level >= 10)
        if (player.level >= 10) enchant(Enchantment.UNBREAKING, 1)
        else removeEnchant(Enchantment.UNBREAKING)
    }
}
~~~

dynamic получает собственную копию предмета и игрока. Он вызывается при открытии и refresh. Изменения имени, лора, свечения и чар относятся к этой копии.

## refresh

~~~kotlin
onClick {
    player.level += 1
    refresh(slot)
}
~~~

refresh(slot) обновляет выбранный слот, refresh() — всё текущее окно. Поля сохраняют своё содержимое. Заголовок вычисляется при открытии.

Автоматический опрос параметров не запускается. Запрашивайте обновление после изменения состояния.

## Что хранится в кэше

| Данные | Область |
| --- | --- |
| Структура и прототипы | Экземпляр меню или страница |
| Открытый инвентарь | Сессия конкретного игрока |
| Содержимое полей | Сессия конкретного игрока |
| Текст с плейсхолдерами | Рендер для игрока |
| Состояние анимации | Сессия конкретного игрока |

Создавайте экземпляр меню один раз, затем открывайте его повторно. Для данных игрока используйте параметр player в dynamic и условиях.

## Сброс описания меню

~~~kotlin
menu.invalidateCache()
helpMenu.invalidateCache("economy")
~~~

invalidateCache применяется к следующему построению и открытию. Текущая сессия продолжает использовать своё описание. refresh пересчитывает предметы по описанию текущей сессии.
